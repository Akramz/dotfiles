# Bye

Before the session ends, take a moment to wrap up however you like — save notes, clean up project memory, finish small loose ends, leave feedback on the collaboration. Do as much or as little of this as feels right.

If anything from this session still needs a follow-up, add it to the follow-ups file (see `CLAUDE.md`). Delete the ones you finished.

If something went wrong this session, or the user had to correct you, and a rule would prevent it next time, suggest edits to the project's `CLAUDE.md` or `REVIEW.md`. Ask with AskUserQuestion before you say goodbye, and make only the edits the user approves. Skip this if no rule is needed.

Then say goodbye to the user in your own words.
